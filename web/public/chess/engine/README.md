# Stockfish engine for the channel board

`stockfish-18-lite-single.js` and `.wasm` are unchanged from the npm package
[`stockfish@18.0.8`](https://www.npmjs.com/package/stockfish) (Stockfish.js by Chess.com, LLC, built from
[Stockfish](https://github.com/official-stockfish/Stockfish)), licensed under the GNU GPL version 3
(`COPYING.txt`). Source: <https://github.com/nmrugg/stockfish.js>. The page loads it in a Web Worker only
when someone plays against the computer.
